Childcare Operations & Data Analytics Dashboard

Project Overview:

This project focuses on using Microsoft Excel to analyze childcare enrollment, classroom capacity, tuition revenue, and overall operational performance.

The goal was to identify trends, track key performance indicators (KPIs), and provide insights that could support business decisions.

Tools Used:

Microsoft Excel

PivotTables and PivotCharts

Data Cleaning and Validation

KPI Dashboards

Exploratory Data Analysis

Revenue Scenario Analysis

Dataset:

The original analysis included 59 student records and operational information related to enrollment, tuition, classroom capacity, and family balances.

Project Objectives:

Analyze enrollment trends.

Evaluate classroom capacity and utilization.

Examine tuition revenue and outstanding balances.

Identify potential opportunities to increase enrollment.

Create dashboards to communicate business performance.
